# GoMikeDesigns

## Live Demo

[View the live website](https://andreeavp.github.io/GoMikeDesigns/)

## Project Overview

GoMikeDesigns is a website optimisation project completed as part of the OpenClassrooms Web Developer programme. The original website was provided, and my task was to improve its performance, accessibility, search engine optimisation and overall code quality.

## Key Improvements

* Converted and compressed images to reduce page loading times
* Used modern WebP image formats
* Removed unnecessary and unused code
* Corrected HTML and CSS validation errors
* Added ARIA attributes to improve accessibility
* Improved responsive layout and content alignment
* Optimised font and image loading
* Added relevant metadata and keywords for SEO
* Improved the website's overall performance and maintainability

## Technologies and Tools

- HTML5
- CSS3

- Chrome DevTools
- W3C HTML and CSS Validators
- WebP image optimisation
- Responsive design techniques

  ## What I Learned

This project helped me understand how performance, accessibility and SEO affect the quality of a website. I gained practical experience optimising images and code, fixing HTML and CSS validation errors, using accessibility attributes and testing improvements with browser development tools.
